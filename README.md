# Pocketful

Budgeting and shared expenses, built around the days and weeks ahead.

**[Open Pocketful](https://pocketful.pages.dev/login)**

Pocketful helps you keep track of what you can spend today and what you owe friends. It combines personal budgets, shared expenses, and event budgets in one web app.

## What it does

- Works out a daily spending amount from your remaining budget and time.
- Tracks expenses by budget category.
- Splits shared expenses and keeps a net balance for each person.
- Sets separate budgets for events with a start and end date.
- Supports multiple currencies.
- Offers email magic-link sign-in.

The public landing page includes an interactive expense-splitting demo you can try before signing in.

## Stack and deployment

- **Supabase** for the backend.
- **Cloudflare Pages** for hosting at `pocketful.pages.dev`.

## Repository status

The live app is deployed through a direct upload to Cloudflare Pages. This repository currently contains the project overview; the application source and local setup instructions have not been added yet.
